Стартовая задача: создан эхо-бот, повторяет сообщения пользователя. При использовании команды "/help" бот выдает доступные команды.

---

Пример диалога с пользователем (U - пользователь, B - бот):

U: "/start"

B: "Здравствуйте! Отправьте мне любое текстовое сообщение."

U: "Привет"

B: "Вы ввели «Привет»"

U: "/help"

B: "Я эхо-бот. Повторю то, что вы напишите."
